# 校园快递配送系统 — 依赖说明

本文档列出系统三端（后端、后台管理端、小程序端）的全部依赖、运行环境及中间件。

---

## 一、运行环境依赖

| 类别 | 名称 | 版本要求 | 说明 |
| --- | --- | --- | --- |
| 语言运行时 | JDK | 11（兼容 1.8 源码） | 后端运行/编译 |
| 构建工具 | Maven | 3.9+ | 后端打包 |
| 数据库 | MySQL | 8.x | 业务数据存储 |

## 四、微信小程序端依赖

小程序端为**微信原生小程序**，未引入第三方 npm 依赖，仅使用微信小程序基础能力：

- 微信基础库能力：`wx.login`、`wx.request`、`wx.navigateTo`、`wx.setStorageSync` 等
- 页面与组件：WXML / WXSS / JavaScript 原生编写
- 配置：`app.json`（页面、tabBar、窗口）、`project.config.json`（AppID 等）

## 五、中间件/外部服务

| 服务 | 用途 | 说明 |
| --- | --- | --- |
| MySQL（127.0.0.1:3306） | 业务数据 | 数据库 `campus_pickup` |
| Redis（127.0.0.1:6379） | 缓存/Token | 登录令牌、下拉选项缓存等 |
| 微信开放平台接口 | 微信登录 | `jscode2session` 换取 openid |
| 阿里云 OSS | 图片存储 | 轮播图等图片上传 |
